# Версии закреплены НАМЕРЕННО, все до одной — включая те, что ставятся сами
# следом за нужными нам.
#
# Раньше здесь стояли голые имена, и хостинг при каждом деплое ставил то, что
# оказалось свежим в тот день. Значит, магазин мог лечь от чужого обновления —
# без единого нашего коммита, и искать причину пришлось бы в коде, которого
# никто не менял.
#
# Этот набор — ровно тот, на котором прогон в GitHub прошёл зелёным на всех
# четырёх сочетаниях (две базы × два часовых пояса).
#
# Как обновлять: поднять версию здесь, дождаться зелёного прогона, и только
# потом деплоить. Обновление — такая же правка, как любая другая, и проходит
# тот же путь.
#
# Питон закреплён отдельно, в .python-version: без него хостинг однажды сам
# сменит версию языка — и это будет выглядеть как «ничего не меняли, а всё
# сломалось».
